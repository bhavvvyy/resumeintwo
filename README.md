# ResumeInTwo

> No Prompt. Just Resume.

ResumeInTwo is a simple, fast resume builder. Fill in a form, see your resume update live, and download a clean, print-ready A4 PDF — no prompts, no accounts, no fuss.

## What it does

- Fill in your details in a simple form
- Live preview as you type
- 10 field templates — pick a sample resume for your field (including Data Analyst)
- A4 PDF download, ready to print or share
- ATS score to check how well your resume matches typical applicant-tracking checks
- Admin page (`admin.html`) to view saved resumes

## How to use

1. Open the live site (or open `index.html` in a browser).
2. Fill in your name, role, contact details, experience, education and skills — or click **Load Sample Resume** to start from a sample.
3. Check the live preview and your ATS score.
4. Tick "I agree my details will be saved" and click **Download PDF** to save your resume.
5. Open `/admin.html` to view resumes saved from the site.

## Tech

- HTML / CSS / JavaScript — the whole site is static, with no build step
- Supabase (optional) — used for saving resumes so they can be listed on the admin page

## Deploy

Deploy the files as a static site (for example, on Netlify): `index.html` is the homepage and `admin.html` is available at `/admin.html` on the same site.
